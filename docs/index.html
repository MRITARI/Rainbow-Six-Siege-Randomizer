R6 RANDOMIZER

Random Operator and Loadout Utility

Overview

The R6 Randomizer is your go-to companion for Rainbow Six Siege, helping you pick a random operator for Attackers or Defenders. It’s a quick way to keep your gameplay fresh and unpredictable, with full control over which operators are included.

Changelog

v1.3.1 (Latest)

  • YEAR 11 SEASON 3 — Operation Split Fire
  • Added new operator: Noor

v1.3.0

  • YEAR 11 SEASON 1 — Operation Silent Hunt
  • Added new operator: Solid Snake
  • Live API Integration: The app now syncs directly with R6 Roulette to get the latest operator data.
  • Auto-Caching: Data is fetched once at startup and cached locally to ensure fast performance and offline support.

v1.2.1

  • Added loadout randomizer
  • Primary weapons, Secondary weapons, Attachments, Grips, Scopes, Gadgets

v1.2.0

  • YEAR 10 SEASON 3 — Operation High Stakes
  • Added new operator: Leon "Denari" Winzenried
  • Transparent for an overlay-like look.
  • Updated hotkey logic (Shift + F5 to toggle visibility).
  • Note: This is not a true game overlay like Discord, Steam, or NVIDIA Overlays.
  • Overlay now locks to the top-right corner of the screen.
  • Minor UI improvements and bug fixes.

v1.1.1

  • Minor changes.

v1.1.0

  • Operators enabled/disabled state now saves automatically to a config file.
  • When reopening the app, previously selected operators are restored.

v1.0.0

  • Initial release.
  • Randomize operators for Attackers or Defenders.
  • Enable or disable operators in settings.
  • Prevents duplicate picks until reset.
